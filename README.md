# C++ Fundamentals 💻

A structured collection of C++ programming exercises and mini-projects created as part of my software engineering learning journey.

## 📚 Topics Covered

- Basic Input & Output
- Variables and Operators
- Conditional Statements
- Switch Statements
- Loops (for, while, do-while)
- Problem-Solving Exercises

## 📁 Repository Structure

| Folder | Contents |
|---|---|
| `01-basics` | Input, output, variables and operators |
| `02-conditions` | Decision-making statements |
| `03-switch-statements` | Switch-case exercises |
| `04-loops` | Loop-based programs |
| `05-mini-projects` | Small C++ applications |

## 🛠️ Technologies

- Language: C++
- IDE: Dev-C++
- Version Control: Git & GitHub

## ▶️ How to Run

Compile an individual program using a C++ compiler, for example:

```bash
g++ 04-loops/multiplication-table.cpp -o multiplication-table
./multiplication-table
```
